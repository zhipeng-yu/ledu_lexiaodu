乐小读使用说明

公司顾问内部版 · Windows 10/11 64 位

安装

  1. 双击 Lexiaodu-Setup 安装包，按默认步骤完成安装。
  2. 如果 Windows 显示“Windows 已保护你的电脑”，点击更多信息，核对应用为“乐小读”后点击仍要运行。
  3. 安装完成后，可立即启动；以后从桌面或开始菜单双击乐小读。

开始使用

  1. 点击“新建会话”，输入家长问题后发送。
  2. 需要分析聊天截图时，点击“选择截图”，每条消息可选择一张图片。
  3. 聊天只保存在当前 Windows 账户。本机覆盖安装或卸载后重装，不会主动删除原聊天。

遇到报错

  1. 先检查网络，再点击失败消息旁的“重试”。
  2. 仍无法使用时，点击窗口右上角复制诊断信息，把复制内容发给管理员；诊断信息不包含密钥和聊天正文。
注意：本安装包未购买代码签名证书，仅通过公司内部私密渠道分发。不要转发安装包或诊断日志给无关人员。
