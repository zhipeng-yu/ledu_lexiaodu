# 乐小读五分钟演示脚本

本脚本只使用虚构演示对话，不截取真实家长聊天。演示前应完成 `docs/MANUAL_TEST_CHECKLIST.md` 的环境项。

## 0:00–1:00 预检与启动

在项目根目录执行：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.\.venv\python.exe -B scripts\verify_day5_queries.py
.\.venv\python.exe -B scripts\verify_doubao.py
.\.venv\python.exe -m lexiaodu
```

预期固定查询和豆包配置验证均显示 `[PASS]`，随后直接打开乐小读独立聊天主窗口。真实豆包预检会产生少量 Token 费用。

## 1:00–2:00 独立会话与连续追问

1. 点击“新建聊天”，重命名为“虚构演示”。
2. 输入：“家长担心线上课时间长，孩子坐不住，我应该先了解哪些情况？”
3. 发送后确认先出现顾问消息，再出现明确标注的离线演示回复。
4. 继续追问一句，再新建第二个会话并来回切换，确认两个会话的内容互不混入。

讲解要点：每个会话拥有独立上下文；当前默认助手不会查询或编造公司事实，生产原文档顾问接入前不用于正式答复。

## 2:00–3:00 截图、OCR 与人工校正

提前在任意纯文本窗口显示以下虚构消息：

```text
家长：线上课一节课太长，孩子坐不住，我想了解休息安排。
```

1. 在当前会话点击“框选截图”，只框住上述消息；也可把虚构截图复制到剪贴板后点击“粘贴截图”。
2. 在“OCR 文字校正”窗口核对文字和发言人。
3. 若 OCR 有错，直接修改；遗漏内容可手动粘贴补充。
4. 点击确认，随后切换会话再切回，确认校正文案仍只属于截图开始时的会话。

讲解要点：截图以随机文件名的加密 `.bin` 保存，原图不进入助手上下文；只有顾问确认后的文字进入所属会话。

## 3:00–4:00 搜索、恢复与删除

1. 使用左侧搜索框按标题或虚构消息内容查找会话，再清空搜索。
2. 关闭应用并重新启动，确认会话、消息和 OCR 校正文案恢复，未完成请求不会自动重发。
3. 删除第二个虚构会话，确认侧栏和时间线立即清空对应内容；再次启动后它仍不出现。

讲解要点：标题、消息、OCR 校正文案、回复卡和附件均加密保存在本机；主密钥受当前 Windows 用户范围的 DPAPI 保护。

## 4:00–5:00 能力边界与收尾

1. 指出“生成正式回复”和“会话资料”当前禁用，并阅读其说明。
2. 说明后续知识库以 Word、PDF、PPT、Excel 等原文档为唯一长期知识源；OCR、解析文本和文本切片只作为临时中间产物，上传方舟并校验后删除。
3. 删除所有虚构演示会话并关闭应用，不把演示文字发送给真实联系人。

若任一步未满足预期，停止正式演示并按手动清单记录阻断，不临场修改知识或关闭风险门控。
