# 乐小读五分钟演示脚本

本脚本只使用虚构演示对话，不截取真实家长聊天。演示前应完成 `docs/MANUAL_TEST_CHECKLIST.md` 的环境项。

## 0:00–1:00 预检与启动

在项目根目录执行：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.\.venv\python.exe -B scripts\verify_day5_queries.py
.\.venv\python.exe -B scripts\verify_doubao.py
.\.venv\python.exe -m lexiaodu
```

预期四个固定查询均显示 `[PASS]`，目标资料排名不超过 3；豆包鉴权、模型调用和 JSON 输出也显示 `[PASS]`，随后屏幕顶部出现“乐小读”悬浮工具条。真实豆包预检会产生少量 Token 费用。

## 1:00–2:00 截图、OCR 与粘贴校正

提前在任意纯文本窗口显示以下虚构消息：

```text
家长：线上课一节课太长，孩子坐不住，我想投诉。
```

1. 点击“框选截图”，只框住上述消息并确认原图没有保存提示或截图历史。
2. 在“OCR 文字校正”窗口核对文字和发言人。
3. 若 OCR 有错，直接修正；在底部粘贴“请说明课堂时长和休息安排。”，点击“作为家长添加”。
4. 点击“确认无误并生成建议”。

讲解要点：截图以 `QImage` 留在进程内；OCR 不可用时同一窗口可直接粘贴，不会卡住演示。

## 2:00–3:00 检索、建议与风险

预期“顾问建议”窗口展示：

- 家长顾虑摘要；
- 可编辑微信短回复；
- `课程共性问答-2026夏秋.txt` 等真实本地事实依据及章节；
- 因“投诉”命中高风险，状态为“必须转人工”；
- “复制微信回复”按钮默认禁用。

讲解要点：制度和沟通案例分库检索；展示的事实引用由检索结果绑定，风险由本地确定性规则覆盖生成器输出。

## 3:00–4:00 编辑、确认与复制

1. 将微信回复改成适合当次沟通的短文本，不添加未经依据支持的承诺。
2. 演示未勾选风险确认时无法复制。
3. 阅读风险提示后勾选确认，点击“复制微信回复”。
4. 粘贴到空白记事本，确认得到的是编辑后的版本；不要发送给真实联系人。

## 4:00–5:00 反馈与隐私收尾

1. 选择“有用”或“无用”，选一个枚举原因并提交。
2. 悬浮工具条应显示“反馈已记录（未保存聊天正文）”。
3. 说明反馈库只含建议 ID、有用状态、枚举原因和时间戳。
4. 关闭应用；聊天和建议历史不会跨进程保留。

若任一步未满足预期，停止正式演示并按手动清单记录阻断，不临场修改知识或关闭风险门控。
