## 官方接口证据

访问日期：2026-08-10。

### Files API（直接文件输入）

- 官方页面：[文件输入(File API)](https://www.volcengine.com/docs/82379/1885708?lang=zh)，页面显示最近更新时间 2026-08-07 14:43:16。
- 上传端点为 `POST /api/v3/files`，本地原文件可作为二进制 `file` 上传，`purpose=user_data`；上传后的 File ID 可被多次推理请求复用。
- 方舟默认托管空间的单文件上限为 512 MB、账户总容量 20 GB；默认保存 7 天，`expire_at` 可设为 1–30 天。
- 上传后必须查询文件状态，只有 `status=active` 才能在 Responses API 或 Chat API 中作为 File ID 使用；Responses API 使用 `input_file.file_id`。
- 删除端点为 `DELETE /api/v3/files/{file_id}`。文件上传和管理本身不收费；模型推理仍按所用模型计费。
- 当前“文档”支持表只列出 `.pdf`（`application/pdf`），没有 DOCX、PPTX 或 XLSX。因此不能把 PDF 的结果外推到三种 Office 格式。
- PDF 上传的是原始二进制，但服务端会把 PDF 分页预处理为图片；这满足“本地不提取、不切块、不 OCR”，不等于“云端完全不处理”。
- Files API 不原生返回页码定位字段。页码必须在提示词中要求模型输出，并由能力探针校验，不能仅凭上传成功判定可用。

### 文档知识库（Office 格式候选路径）

- 官方页面：[文档知识问答核心流程](https://www.volcengine.com/docs/84313/1254457?lang=zh)和[知识库常见问题](https://www.volcengine.com/docs/84313/1606319?lang=zh)说明：非结构化文档支持 DOCX、PPTX、PDF，结构化或兼容路径支持 XLSX。
- 该路径会在云端执行解析、切片、向量化和建索引，图片/表格还可能使用 OCR。因此它只符合“上传原文档、本地不保存处理后文本段”，不符合“任何位置都不处理原文档”。
- 知识库是独立服务，需要单独的知识服务 API Key、知识库资源与费用审批。官方说明从上传文档开始计费；仅删除文档不停止资源计费，删除知识库或退订才停止。

## 验证标准

每种格式必须分别满足：

- 上传前后 SHA-256 完全一致；
- 文本、表格和图片承载内容均能读取；
- 小型受控样本回答准确率 100%；
- 页码、幻灯片、章节或工作表/单元格定位准确率至少 95%；
- 文件复用方式明确，或已批准不可复用的生命周期；
- 超时和一次瞬时错误重试得到验证；
- 保存、删除和服务端残留行为有官方证据并获批准；
- 提交文件、日志和报告不包含问题、答案、路径、文件 ID 或文档正文。

任何格式只要缺少上传支持、精确定位、清理验证或隐私审批，即判定为 `NO_GO`，不得静默进行本地提取、OCR、转换或切块兜底。

## 已知限制

- PDF 的当前模型/账户已证明能够读取文本表格和扫描图片并输出页码，但 4/4 稳定性门槛未满足，不能进入生产。
- 远端上传超时可能发生“服务端已创建、客户端未收到 File ID”，此时无法在异常路径按 ID 清理。除非引入可核对的上传批次标记/服务端幂等能力或受控残留清理流程，否则该风险本身足以维持 `NO_GO`。
- DOCX、PPTX、XLSX 的官方可行候选是独立文档知识库，不是 Files API；该路径会云端解析/切片并可能持续计费，当前账户未配置，未实测。
