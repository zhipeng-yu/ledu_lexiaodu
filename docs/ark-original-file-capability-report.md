## 验证标准

每种格式必须分别满足：

- 上传前后 SHA-256 完全一致；
- 文本、表格和图片承载内容均能读取；
- 小型受控样本回答准确率 100%；
- 页码、幻灯片、章节或工作表/单元格定位准确率至少 95%；
- 文件复用方式明确，或已批准不可复用的生命周期；
- 超时和一次瞬时错误重试得到验证；
- 保存、删除和服务端残留行为有官方证据并获批准；
- 提交文件、日志和报告不包含问题、答案、路径、文件 ID 或文档正文。

任何格式只要缺少上传支持、精确定位、清理验证或隐私审批，即判定为 `NO_GO`，不得静默进行本地提取、OCR、转换或切块兜底。
