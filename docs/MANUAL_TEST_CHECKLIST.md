## 后续原文档知识库硬约束

- Word、PDF、PPT、Excel 等原文档是后续知识库唯一长期知识源，不能再以处理后的 OCR 文本或文本切片代替原文件。
- OCR、解析文本和文本切片只允许作为本地筛选、文件选择、上传或方舟处理过程中的临时中间产物。
- 原文档成功上传方舟并完成完整性校验后，必须删除本地 OCR 正文、文本切片、临时预览和可还原正文的缓存。
- 本地长期数据最多保留文件指纹、文件类型、脱敏状态、上传状态、方舟文件 ID 和审计时间，不保留可还原公司正文的明文。
- 现有 `knowledge.sqlite3` 中的旧 OCR/切片正文必须纳入后续迁移清理；本次重建仅用于验证 legacy 回滚链路，不代表新架构验收通过。
