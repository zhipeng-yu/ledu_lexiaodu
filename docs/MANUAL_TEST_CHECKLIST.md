# 聊天截图手动测试清单

只可使用合成或脱敏截图；禁止在此文件、仓库或验收记录中保存真实家长数据、截图或聊天正文。

| ID | 操作 | 通过标准 | 结果/证据 |
|---|---|---|---|
| SV-01 | 在个人聊天中选择一张合成的长截图并发送 | 仅接受一张 PNG/JPG/JPEG/WebP；方舟以 `high` 细节模式读图，回复可理解截图内容 | 待人工验收 |
| SV-02 | 在至少三名参与者的合成群聊长截图中发送 | 方舟以 `high` 细节模式读图，回复可区分群聊上下文 | 待人工验收 |
| SV-03 | 发送参与者身份无法判断的合成群聊截图 | 只向顾问追问一个关键身份问题；不生成可直接发给家长的话术 | 待人工验收 |
| SV-04 | 发送带截图的会话后完全退出并重启 | 截图缩略图和会话上下文可恢复；不自动重发请求 | 待人工验收 |
| SV-05 | 让带截图的请求失败后点击重试 | 重试沿用原截图和请求上下文，最终只保留一条助手回复 | 待人工验收 |
| SV-06 | 删除含截图的会话后重启 | 会话、截图记录和对应的加密文件均不再出现 | 待人工验收 |
| SV-07 | 选择无效/损坏的图片文件，并查看已损坏的已存截图 | 无效文件不发送；损坏截图显示无法读取且应用不崩溃 | 待人工验收 |
| SV-08 | 在未选择截图时发送纯文本 | 纯文本发送、失败重试和重启恢复行为不变 | 待人工验收 |

只记录案例编号、通过/失败和不含个人信息的错误类别；不要复制图片、聊天内容或方舟回复。
